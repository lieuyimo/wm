# PR27：冻结 12 组真实在线调度的世界模型价值验证（2026-11-12）

## 阶段结论

**已完成真实的在线 CP-SAT、V4 和 V4+pgmpy 运输风险调度策略对照。结果不支持世界模型改进调度结果，暂不将世界模型风险重排策略晋升默认策略。**

本轮不修改 PR #19、不修改主分支、不重新训练 V4 或运输 Bayesian 网络，也没有用事后 Oracle 预测替代在线模型。所有策略在**事先冻结的 12 个合成场景 seed** 上执行真正的业务仿真，并接受同一份资源、机器人运动与业务流程合法性检查。

## 方法出处与既有组件复用

- CP-SAT 候选方案：现有 `BusinessCPSAT.proposals`，并非重新设计调度求解器。
- 世界模型动态：冻结的 RHWM-v1 V4 服务完成事件模型 + 现有合法 `WorkflowDynamics`，只采用 PR26 已证实不改变未来状态的 `shadow` 模式；不把 PR26 实验性随机停顿晋升正式模型。
- 运输风险：PR25 真实训练的 `pgmpy 1.0.0 BayesianEstimator/VariableElimination`（MIT），参考 Tang & Wang (2025) 对 AGV 运输不确定性采用 Bayesian 推断的思路；注意本项目预测的是**超出当前几何路径基线的延迟概率**，不是论文实际的节点障碍概率，未复现其原图结构。
- 多步预测与在线选择：参考 PETS (Chua et al., NeurIPS 2018) 颗粒化滚动预测与预期代价思想，现有 `decision_value.trace_score` 对未完成任务的时长/逾期惩罚及终点距离做 5 步适配，并将 PR25 概率换算为明确标记的期望附加时间项。**该候选评分加法只是工程适配，不是原论文已验证的原创算法。**
- 所有策略使用相同 CP-SAT 候选生成规则与每次求解预算，但运行后的公开状态可能因行动不同而分叉；不能声称所有未来时刻的候选列表完全相同。统计并列报告世界模型额外计算成本。

## 预注册设计

`experiments/world_model_integration/decision_value/pr27_protocol.json` 先于测试提交；本轮明确 12 组 `transport_protocol.json::future_decision_groups`（在 PR24 收集第一批数据之前已固定），不与 PR24/25 的训练、验证、holdout 或 PR26 的 12 组 horizon 测试重合。

- 三条策略：`cpsat`、`v4`、`v4_plus_risk`。
- 真实模拟器：同样公开地图、机器人和样本配置，`_service_duration` 使用同场景 seed 与样本/阶段键控抽样，固定外生随机变量。
- 公开的合成工作任务 deadline：`release+45+5×工作号序位`，作为此阶段固定的实验假设；**非企业现场实际截止时间**。
- 每个决策 CP-SAT 方案上限 4、求解 wall 0.08s、deterministic 0.04；世界模型单次决策额外 CPU 上限 0.5s；状态预测 H5/P3；冻结模型，不训练。
- 评价完成时间、工序截止、完成作业、资源等待、运动阻塞、实际变更方案次数和计算资源；按 **12 个场景组配对**，不以动作、候选或粒子充当独立实验样本。
- 任意数据中出现不合法场景、未来信息泄漏或资源/运动违规必须直接失败；不以无效结果凑实验。

## 严格结论与后续重点

1. **工程闭环已成立：** RHWM-v1 提供动作条件系统状态预测；服务预测可学习；PR25 运输延迟风险可学习；PR26 在已验证的合法系统状态旁路输出运输风险；本轮已用于真实在线 CP-SAT 候选动作评分并验证完整业务轨迹。
2. **世界模型的调度净收益未确立：** V4 没有翻转最终方案，V4+风险翻转 3 次但未改善完成时间与逾期，反而增加平均资源等待；不能写成正向调度改进。
3. **问题不应通过刷随机 seed 或换自造网络掩盖：** 当前小型固定工序场景、CP-SAT 候选密度有限、已知运动规则强、随机机制单一，可能使模型预测价值较小。以上只是解释假说，尚未独立验证。
4. **下一研发不应盲目增加模型头：** 先与企业确认存在不确定运输延迟、真实设备故障和资源状态遥测等业务证据；若要加强合成场景，必须预先设定外生机制及验证协议并注明假设来源，不能补充“使世界模型收益显著”的后验数据。
5. **本科论文可据实呈现：** 重点为“现成概率预测方法 + 合法状态转移 + 有限预算在线调度系统的设计实现”，并报告目前模型收益限制。工程贡献无需伪称新算法。
