## 对下一阶段 RHWM-v2 的工程指向

1. **保留 RHWM-v1 状态转移引擎及验证契约**：不重写资源容量、运动安全和工序后继合法性。
2. **重点升级学习的条件变量表达**：机器人→任务→站点→资源的显式关系、共享资源竞争、服务进展、候选分配关系，以及任务等待状态。
3. **预先固定监督目标**：已有服务完成事件 `p_finish_next`；增加“5步内首次进入服务”的有掩码辅助目标。该目标依赖固定公开续调度策略，不能混同为与策略无关的环境事实。
4. **预先固定真实独立测试**：Train/Validation/新测试 group 不共享外生 seed/结构配置，按组报告 H1/H5/H10，沿用本阶段 Rule 和 V4 基线。无结果调权、无反复开新粒子/种子刷分。
5. **必须接受失败**：若关系式 v2 在独立组上未降低状态/资源误差或恶化服务事件概率，则保留 v1，并据实解释关系网络没有观察到稳定收益。
