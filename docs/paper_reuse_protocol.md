# CP-SAT 与 PETS 集成：冻结的 CPU 验收协议

本轮基于 PR #10 提交 `bea358cdb0b7729655123aa02014d5ff88a64aea`，不改旧 PR 或上游源码。上游版本、环境和训练数据见最终报告。所有任务、服务参数及中断均为仿真假设，不代表真实医疗业务。

开发时先用 Tartu `41000` 普通及集中到达场景检查了可执行性。随后发现五步内机器人未抵达站点时 PETS 可能没有被调用，于是让同一剩余工作量评分的服务项使用概率模型的条件期望；规则组仍使用相同评分公式和已有历史均值。首次试验使用每次求解 0.05 秒墙钟上限，后续复跑发现相同种子下某次额外候选枚举得到 `UNKNOWN`，虽然最终动作与流转相同，候选数量却不一致。为修复可复现性，改为每次求解 **0.5 秒墙钟上限及 0.05 确定性时间上限**、单线程，并显式记录候选枚举截断；最多四次求解。若仍有截断则验收不通过。原试验摘要和截断记录保留，原先用过的 Tartu `45001/45004`、clinic `46000/46002` 不再作为独立确认数据。

**以上已查看过的场景不是独立确认集。** 固定上述求解上限、评分、五步窗口、3 个采样粒子和最多 4 个候选后，仅按任务起终点及释放时刻签名选择以下确认种子，不根据确认结果调节。

| 分组 | Tartu | clinic | 每个种子的场景 |
|---|---|---|---|
| 开发 | 41000、41002 | 42000、42001 | 正常、集中到达、处理中断、到站不可用 |
| 独立确认 | 49002、49003 | 50000、50001 | 同上 |

程序同时检查本轮两组与 PR #8、#9、#10 的训练及测试任务签名，并排除前述本轮试验种子；同一任务表变体只在所属组内复用。每组为两地图×两种子×四场景，即 16 完整场景、4 个地图/种子独立簇。工作站故障窗口由既有无故障最近优先探针按固定规则确定，持续 20 步；它属于线下场景配置，不输入策略或模型。仿真器按 `(seed, sample, phase, station)` 生成服务时长随机值，供各策略复用。

## 模型与评分

只从 PR #9 已生成的 train/validation 事实轨迹提取在完整观测开始并实际完成的服务，计算站点可用时间内的有效时长；故障暂停时间不计入标签。未完成或开始不可见的服务明确排除并计数。轨迹所属测试分组不用于本轮训练；输入只有服务开始时可见的站点先验、历史均值和数量、服务阶段及当前可观察资源需求。训练 MBRL-Lib 原生 5 成员 GaussianMLP 的对数时长概率分布，35 个 CPU 小规模 epoch，训练器、ReplayBuffer 与模型结构均为上游实现；不把损失下降当作调度收益。

三组闭环分别为最近优先+规则预测、CP-SAT+规则预测、CP-SAT+PETS/规则混合预测。CP-SAT 将当前未分配任务按实际取样和送样两阶段建模，机器人为可选资源，强制先取后送、同一机器人和任务不重复，优先最大化当前可分配数量，再最小化 makespan；不虚构工作站容量。最多取四个不同合法匹配。后续五步使用已有最近优先继续分配，未知未来任务/故障维持不可知；相同候选、评分、窗口和外生条件。PETS 使用 3 个随机粒子，并对每个候选使用相同种子序列。最近优先只预测自己的单个候选，它与 CP-SAT 组的计算量不同，必须如实报告。

评分复用 PR #10 的 `W + R, C, D`：窗口内已知未完成任务成本 W、窗口末剩余路程及预计有效服务工作 R、竞争代理 C、路程 D。PETS 将 R 的服务项替换成其对剩余有效步数的预测条件期望；规则组使用已有历史均值估计。PETS 还在已到站且可用时按条件完成概率采样状态转移；移动、任务生命周期和不可用站点由已有规则约束。离散期望截断上限为 60 有效步，确保计算有界。样本尚未完成时不把观测进度冒充完整时长。

## 评价与边界

在最近优先事实执行轨迹上，对三个模型（规则、PR #9 结构化模型、PETS）计算服务完成事件 Brier；PETS 和规则分别报告已完成服务时长 MAE，PETS 报告对连续对数正态混合密度的 NLL 和名义 90% 区间覆盖率。现有结构化完成头不输出时长分布，其 MAE、NLL 和区间覆盖率标记为不可比，而非捏造。一步、三步、五步联合状态正确率另比较完整结构化模型与 PR #9 规则运动混合模型；每 5 个符合条件的窗口抽 1 个，排除未来分配、任务到达或站点可用性变化的窗口。这些窗口只是条件预测诊断，不代表异常发生时的总体精度，也不是独立样本。

闭环报告完成任务、流转时间、实际定义了截止时间的样本超时、每次决策 CPU 耗时、规则预测步数、PETS 前向调用次数、回退和离散安全违规。无截止时间的数据集将超时记为 `null`，不虚构期限。策略差异先逐完整场景配对，再按地图/种子簇进行分层 bootstrap；每地图仅两个种子，不把场景、时间步或候选视为互相独立，也不把该区间解释为稳健泛化证明。只使用历史轨迹训练数据和独立仿真测试，不声称真实业务效果。
