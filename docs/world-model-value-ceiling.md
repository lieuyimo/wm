## 研究判断与停止条件

**E: multiple bottlenecks; 20-step true states outperform 5-step true states, and 5-step truth also beats the predictors**。

这个标签仅是基于明确数值的工作诊断，不自动证明某个瓶颈是唯一因果因素。
- A 候选机会不足：不成立，38/48 个状态差距至少 1 步，25/48 个至少 3 步。
- B 预测误差：存在次要证据，准确 5 步使决策损失从 1.7639 降到 1.2257 步；但 PETS 的 48 次选择全部与规则相同，结构化头仅 1 次改善。
- C 短窗口/评分/未来外生信息：准确 20 步将损失继续降至 0.2812 步，但故障场景贡献了大部分改善；Perfect-State-20 得到未来故障的实际影响，而线上模型不能读到未来故障，故无法仅据此分离窗口长度、评分偏差与外生信息的贡献。
- D 候选集：存在未覆盖的单条合法 robot-task 配对，但没有补充完整可行批次的更优反事实证据，不能定为 D。
**最终选择 E（多瓶颈：有限预测窗口、评分与未知外生事件相互交织，亦存在模型预测误差）。**
**研究建议：不要在当前 5 步 workflow_score 不变的条件下继续盲目训练 PETS/结构化模型；目前缺乏支持直接训练新世界模型的证据；先确认可在线获得的远期信息及其决策价值。**
该建议不构成开发下一代模型、重设评分或扩大候选搜索的自动授权。
本轮停止后不自动训练、改架构、改候选算法或合并 PR。
